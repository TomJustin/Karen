Karen for Windows x64 — Portable Package

Start
1. Extract the entire ZIP archive to a folder you can write to.
2. Double-click Start-Karen.vbs.
3. Karen will start its local backend and open the chat page in your default browser.
4. On first launch, enter your own DeepSeek API Key in Karen's setup window.

Local data
- Encrypted API Key: %LOCALAPPDATA%\Karen\config\api_key.bin
- Profile, chat history and long-term memory: %LOCALAPPDATA%\Karen\data\

Personalization
- Click the gear icon in Karen to change your preferred name, the AI's name, and its personality.
- Changes are saved locally and are used in subsequent conversations.

Your API Key is not bundled in this package. You configure it yourself on first launch.
The package requires an internet connection to reach the DeepSeek API.

To stop Karen
Open Task Manager, find Karen.exe under the Details tab, and end that task.

This is a portable ZIP package. It does not modify Windows environment variables and
does not include or overwrite your personal profile, chat history or memory files.
